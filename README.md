# RAG-project

RAG-система для анализа отчётности X5 Club (2025)
• Разработал систему вопросов и ответов по документам 2025 года (статистика продаж и другие показатели X5 Club).
• Использовал малые языковые модели до 7B параметров и эмбеддинги для поиска по документам (Qwen, Vikhr,
Saiga)
• Оценивал качество набором метрик (RAGAS (ContextRecall, Faithfulness, FactualCorrectness), авторские метрики, (number_match, source_recall), LLM-as-a-Judge)
• Реализовал защиту от prompt injection.
• Систематически перебрал и сравнил подходы (разбиение на чанки, различные методы парсинга pdf, эмбеддинги, защита защищённых данных, сборка итогового проекта)
• Оценка руководителя проекта: 10 баллов.
