# RAG-система для анализа финансовой отчётности X5 Group (Python, PyTorch, LangChain, FAISS, RAGAS):
* Разработал и исследовал модульный RAG-пайплайн по годовому отчёту X5 (300+ стр.): провёл серию ablation-экспериментов по методам парсинга PDF, семантическому и рекурсивному чанкингу, выбору эмбеддингов и LLM.
* Внедрил гибридный поиск (Dense FAISS + лексический BM25 с Reciprocal Rank Fusion), что повысило точность извлечения финансовых показателей (number_match) с 0.38 до 0.78 (+105% отн.), а полноту нахождения эталонных страниц (source_recall) — с 0.23 до 0.47 относительно векторного бейзлайна.  
* Сравнил мультиязычные и русскоязычные энкодеры (e5-small/large, BAAI/bge-m3, deepvk/USER-BGE-M3): адаптация под русский язык (USER-BGE-M3) увеличила точность извлечения чисел с 0.38 до 0.72.  
* Оптимизировал генерацию под ограничения GPU (4-bit NF4 квантование BitsAndBytes): переход с Qwen2.5-3B на Qwen3-4B-Instruct снизил долю галлюцинаций, подняв метрику Faithfulness с 0.36 до 0.91.   
* Реализовал фреймворк автоматической валидации (RAGAS + кастомные метрики численной погрешности и страничного покрытия + LLM-as-a-Judge на базе Gemini API с автоматической ротацией ключей и контролем rate-limits).
